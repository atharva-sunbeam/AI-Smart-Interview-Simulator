# Knowledge Base Builder

## Purpose

The Knowledge Base Builder combines chunk content and metadata into a single structured dataset that serves as the source for embedding generation and vector database storage.

---

## Responsibilities

### load_chunks()

Loads chunked content records generated by the chunking pipeline.

### load_metadata()

Loads metadata records generated by the metadata builder.

### merge_records()

Combines chunk content with metadata using the shared `chunk_id`.

### save_knowledge_base()

Stores the final dataset in CSV format.

---

## Output File

Location:

```text
datasets/processed/knowledge_base.csv
```

## Output Schema

| Field       | Description                |
| ----------- | -------------------------- |
| chunk_id    | Unique chunk identifier    |
| document_id | Source document identifier |
| topic       | Content category           |
| content     | Chunk text                 |

## Benefits

* Single source of truth for embeddings
* Simplifies vector database ingestion
* Preserves traceability through metadata
* Enables topic-based retrieval
* Supports future RAG pipeline expansion

---

## Future Enhancements

Additional metadata fields may be added:

* source_type
* source_url
* difficulty
* tags
* created_at

These fields can improve retrieval quality and filtering capabilities without changing the overall architecture.
