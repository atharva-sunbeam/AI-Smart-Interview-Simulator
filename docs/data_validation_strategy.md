# Data Validation Strategy

## Purpose

Data validation ensures that collected datasets are clean, consistent, and suitable for downstream processing in the AI-Powered Smart Interview Simulator.

Without validation, poor-quality data can negatively affect chunking, embeddings, retrieval quality, and final interview responses generated by the system.

---

## Why Validate Datasets?

The project relies on data collected from multiple public sources. Validation helps identify:

* Duplicate questions
* Empty or incomplete records
* Formatting issues
* Extremely short or low-quality entries
* Data collection errors

Validating data before preprocessing reduces noise and improves overall knowledge-base quality.

---

## Key Validation Metrics

### 1. Total Questions

Measures the overall size of the collected dataset.

Example:

* 100 questions
* 500 questions
* 5000 questions

A larger dataset generally improves knowledge coverage.

---

### 2. Unique Questions

Measures how many distinct questions exist after removing duplicates.

Higher uniqueness indicates better dataset diversity.

---

### 3. Duplicate Questions

Measures repeated entries within the dataset.

Example:

"What is a Python list?"

appearing multiple times.

Duplicates should be minimized before generating embeddings.

---

### 4. Empty Lines

Detects blank records caused by scraping or formatting issues.

These records provide no useful information and should be removed.

---

### 5. Average Question Length

Measures the average number of characters per question.

This helps identify:

* Extremely short questions
* Incomplete records
* Abnormally long entries

---

## Impact of Duplicates on RAG Systems

Duplicate content can significantly reduce Retrieval-Augmented Generation (RAG) performance.

### Increased Storage Usage

Duplicate questions create unnecessary embeddings and consume vector database storage.

### Redundant Retrieval Results

The retriever may return the same question multiple times instead of diverse relevant content.

### Reduced Knowledge Diversity

Duplicate entries occupy space that could be filled with new concepts and interview topics.

### Lower Response Quality

Repeated context can bias generated answers and reduce the usefulness of retrieved information.

## Success Criteria

A dataset is considered valid when:

* Duplicate count is minimal
* Empty records are removed
* Question formatting is consistent
* Average question length is reasonable
* Dataset size matches collection expectations

Validated datasets provide higher-quality inputs for embedding generation and retrieval operations.
