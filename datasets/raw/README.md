# Raw Dataset Directory

This directory contains raw text datasets collected from various sources before cleaning, chunking, and metadata enrichment.

## Files

### python_questions.txt

Stores Python interview questions, coding challenges, and conceptual questions.

### sql_questions.txt

Stores SQL interview questions including queries, database concepts, joins, indexing, and optimization topics.

### data_engineering.txt

Stores data engineering interview questions covering ETL, data pipelines, Kafka, Spark, Airflow, and distributed systems.

### ml_questions.txt

Stores machine learning interview questions including algorithms, model evaluation, feature engineering, and deployment topics.

### job_descriptions.txt

Stores job descriptions collected from recruitment platforms to identify required skills, technologies, and role expectations.

### interview_experiences.txt

Stores real-world interview experiences collected from public sources such as Glassdoor and AmbitionBox.

## Purpose

These raw files serve as the initial data collection layer for the knowledge base pipeline before preprocessing and storage in the unified knowledge base.
